Entry for make.fun bounty **Funniest Forecast for a City That Isn't**
($2, winner takes all): one line, at most 120 characters, the funniest
forecast for a city that doesn't exist, judged pairwise by a house judge.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> In Netherbrough, fog arrives at 9am and refuses to leave until someone apologises; the mayor has apologised twice.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
